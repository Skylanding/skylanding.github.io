# 喜欢听“只有两个小时的假期”，从繁忙中抽离出纯真的自由

因为 INFOCOM'26 的缘故又来了日本！

从 25 年春节后的初次旅行开始就爱上了在日本的单人背包游。

第一次从大阪坐了第一次夜巴到达东京，夜晚的街头弥漫着轻松的气息，也或许是自己的心情终于轻松。在富士山的河口湖环游了四个小时，在藤泽吃到幸福感满满的 chirashi 和猪排。从江之岛的湘南电铁到镰仓的阳光海岸，旅途以秋叶原逛街结尾。

![藤泽的 chirashi](../img/blog/0522_26/chirashi.jpeg)

![镰仓长谷](../img/blog/0522_26/hase.jpeg)

![秋叶原](../img/blog/0522_26/akiha.jpeg)

第二次旅游在关西地区徘徊。京都不愧旅游胜地，让人流连忘返。京都之外最让我开心的其实并不是宇治奈良，而是北边的比睿山和南边的和歌山。比睿山的延历寺并不人满为患，提供了一种别样的宁静体验。乘缆车横穿山脉，从滋贺下山到达琵琶湖。小小县城别有味道。和歌山城也有别样魅力，庭院维护得不错，山城景色和蓝天白云相得益彰。

![京都猫头鹰](../img/blog/0522_26/owl.jpeg)

![比睿山延历寺](../img/blog/0522_26/yanli.jpeg)

![宇治川](../img/blog/0522_26/uji.jpeg)

这次在 Aki 的推荐下去了 Tohoku！主要是仙台和松岛海岸。我真的也很喜欢仙台这个小城市，所有的人流围绕着仙台站涌动，来来往往的白领、大学生、高中生，还有旅客将这个小城装点得格外繁忙。在这里遇到了第一次地震，正好在 donki 六楼逛街，也是人生的独特体验了。

另外神户也给我留下了深刻印象，品尝了六甲牧场冰淇淋和神户牛肉，神户大学的景色也不虚此行。
