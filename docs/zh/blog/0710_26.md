# ACL26 圣地亚哥游记

从 San Jose 飞到了 San Diego 来参加 ACL'26，恰逢 250 周年独立日庆典。

初见 SD，海岸非常美丽，傍晚散步的人们惬意闲适。

![海港](../img/blog/0710_26/harbor.jpeg)

![街边的花](../img/blog/0710_26/flower.jpeg)

领完 badge 后直接来到 SD Zoo，这里的盛名早有耳闻。

![圣地亚哥动物园](../img/blog/0710_26/zoo.jpeg)

![好大的河马](../img/blog/0710_26/zoo2.jpeg)

这里的建筑也具备独特的风格，值得驻足欣赏。

![博物馆](../img/blog/0710_26/museum.jpeg)

![摩门教堂](../img/blog/0710_26/church.jpeg)

最后的航母晚宴非常满足，不虚此行。迎着晚霞，我们结束了这次 ACL 的行程。
