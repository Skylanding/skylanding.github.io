# COLM26 旧金山游记

这次 COLM 于 10 月在旧金山举行。作为北美 AI/LLM 圈认可度比较高的会议，着实不容错过。

![旧金山街头](../img/blog/1015_26/street.jpg)

恰逢 SF Tech Week，除了会场内部人来人往，外面各种 summit 和聚会也是如火如荼。

![夜晚的街道](../img/blog/1015_26/night.jpg)

这次会议主要是跟着合作者认识了很多新的朋友，然后跟武大的校友们吃了很多饭。说实话，本科的时候感觉都没有认识这么多小伙伴，果然开会站 poster 做展示是假，social 才是真的。

![39 号码头](../img/blog/1015_26/pier39.jpg)

印象深刻的还有参加的两次晚宴。Meta 的晚宴在一个小酒吧里，大家随意聊天，认识了一些朋友。

![Meta 晚宴](../img/blog/1015_26/meta.jpg)

![小酒吧](../img/blog/1015_26/meta2.jpg)

青云则是提供 Waymo 打车去加州科学馆举行，感觉举办得非常有意义！

![邀请函](../img/blog/1015_26/invitation.jpg)

![加州科学馆](../img/blog/1015_26/academy.jpg)

参观了雨林馆和水族馆。

![水母](../img/blog/1015_26/jellyfish.jpg)

![珊瑚](../img/blog/1015_26/coral.jpg)

酒会现场和视频算法负责人聊了一下现在的业界情况，也认识了很多新的朋友。

![酒会](../img/blog/1015_26/drink.jpg)

最重要的是抽奖抽到了腾讯视频年卡！我将化身鹅孝子，直到字节再捞我一次 :D

![腾讯视频年卡](../img/blog/1015_26/raffle.jpg)
