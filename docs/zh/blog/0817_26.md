# 湾区的夏日，最好的朋友们

拖着行李箱回到DCA旁边的公寓，发现一年时光已经弹指过去了。加州残余的阳光气息还在身上没有散去，美东的闷热和阴云便扑面而来。

8月实习的最后几天都是和朋友们一起度过。很高兴在字节认识了这么多新朋友和好朋友，我们在一起玩桌游，聊未来。
ICE的Memo发布后，公司的实习生们立刻炸开了锅。恰逢last day和朋友们聚在一起商量对策，报团取暖，有一种别样的感觉。
倘若还是孤身一人，恐怕也只能缩在工位上刷刷小红书，等待进一步消息和被焦虑淹没。

离开湾区的飞机上，对于full time的渴望几乎达到了极限。我们这个小圈子聚集了本科生，硕士生和一些博士生。
而且很幸运遇到的大家都是非常nice的人，我们玩血染，我们出去聚餐。
深夜打完剧本杀的朋友开车来接你出去一起吃一顿简单的晚饭，聊聊趣事，很早之前我是不敢想这样的事。

实习其实没有多辛苦，最难的时候其实是rebuttal任务太重，赶paper压力很大。但是跟朋友们在的每一天，都感觉在度假一样，惬意愉快。

期待几个月以后，还能跟一些朋友在湾区再会。过去一年在DC闷头写paper攒pub，没有多少朋友。
感谢今年暑期的实习能让我和这群最好的人相遇，也希望大家以后都越来越好。
